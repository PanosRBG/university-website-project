# Webpage Project
#### The following webpage is a university project that uses XAMPP as a host. You can install the page by simply copying the files into a folder inside `/xampp/htdocs`.
---
The project features an Erasmus application that helps university students apply to program and find out if they are eligible to do so.

Some technical features are:

1. User registration
2. User authentication
3. Special admin dashboard
4. MySQL that holds user's information
5. Eligibility application
6. Registration form based on user information
